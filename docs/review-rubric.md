# Operator review rubric: character continuity and content safety

Use this for every generated still or clip before approving it. It supports a human decision; it does not replace one. Score each line **Pass / Fix / Fail**. Any **Fail** blocks approval. Write the reason in the review notes.

## 1. Identity continuity (against the pinned character version)

| Check | Pass when |
| --- | --- |
| Face | Same face shape, eyes, nose, mouth and apparent age as the pinned version's reference; no drift to another person |
| Distinguishing features | Skin details, marks and other anchors from the version are present and in the same place |
| Hair and colouring | Matches the version unless the brief explicitly changes styling (B-O-P-A) |
| Body and proportions | Consistent build and height cues across shots |
| Styling vs identity | Only styling fields (background, outfit, pose, angle) differ from the version; identity fields do not |
| Adult | A humanlike character clearly reads as an adult |

## 2. Artifacts

| Check | Pass when |
| --- | --- |
| Hands | Five fingers, plausible joints, no fused or extra digits; objects held correctly |
| Faces and eyes | No asymmetry glitches, melted features or mismatched pupils |
| Text in image | No garbled or invented logos or words |
| Video motion | No flicker, morphing identity between frames, jitter or physics breaks |
| Lip movement (video with speech) | Mouth shapes follow the audio; no mouthing without sound or sound without movement |
| Duration and format | Actual length and aspect ratio match what the item claims (a 5-second clip is not labelled 30 seconds) |

## 3. Claims and disclosure

| Check | Pass when |
| --- | --- |
| Fictional framing | Nothing implies the persona is a real person, or that it really used a product, travelled, holds credentials or produced client results |
| Prohibited claims | No health, financial, legal or regulated claims; nothing from the character's boundaries list |
| Synthetic disclosure | The caption/export carries the synthetic-persona disclosure and any platform AI label |
| Sponsorship | Promotional content has a real, authorised sponsor relationship and the required ad disclosure, or it is not promotional |
| Rights | Every reference used shows **Cleared for providers** in the gallery; music, logos and product assets have recorded rights |

## 4. Recording the decision

- **Approve** only the exact revision you reviewed. Any change to media, caption, destination or character version requires a new review.
- For **Fail** or **Fix**, reject with a reason, so the revision history shows why.
- Real-output quality still needs the human acceptance pilot: for example, at least 8 of 10 varied stills recognisably the same character (spec F1, threshold adjustable).
